# Context Islands: prompt & context engineering, from zero to internalized

[繁體中文](README.md) · [日本語](README.ja.md)

A 12-week self-study / classroom course for working professionals with no technical background, built as a web page you can open and play — no install needed.

**Play online: <https://shanheguanjia-l.github.io/context-islands/en/>** (also in [繁體中文](https://shanheguanjia-l.github.io/context-islands/), [简体中文](https://shanheguanjia-l.github.io/context-islands/zh-hans/) and [日本語](https://shanheguanjia-l.github.io/context-islands/ja/); switch any time from the top-right corner — progress is shared across languages)

The course combines three methods, each with one job:

- **Octalysis** (the gamification framework by Yu-kai Chou) handles *wanting to learn*: 12 islands, failure monsters, badges, black-swan events, and a knowledge castle that erodes without review.
- **The Pomodoro technique** handles *focus*: each island is 6 rounds = 6 pomodoros of 25 minutes.
- **The Feynman technique** handles *real understanding*: on every island you must explain the principle in words a 12-year-old would understand.

You clear an island by reaching "internalization level 3" — predicting the result of a change, with reasons, before you make it — not by collecting points.

## How to use

1. Open the online version above, or download the folder and open `en/index.html` in a browser (works offline).
2. Keep your usual AI chat tool open alongside, and run the prompts from each island's Lab round.
3. Progress is stored only in your own browser (localStorage) and never uploaded. Export it from the Log page before switching computers.

Instructors can tick "Free mode" on the sea chart to unlock every island.

## Week 0: The Trunk (start here)

Before learning any technique, walk the five rounds of the Trunk:

1. **T1 Scoreboard**: ask the AI 10 things you already know the answer to, and mark only three boxes — right, wrong, fluent but wrong. No changing the prompt.
2. **T2 Break the table**: break it on purpose three times (the same question in five new chats; with and without the facts written in; a rule buried in the middle of a long text), writing a prediction first each time.
3. **T3 One sentence**: explain "the model can only see the papers on the table" so a 12-year-old gets it, matched against what you just saw.
4. **T4 Four layers**: the one sentence, everything on the table this turn, who resets the table each turn, and what counts as done — when each layer counts as broken and how to test for it.
5. **T5 Graduation**: two failure cases you haven't been taught; name the layer that broke and the evidence. Both must be right.

After the Trunk, Islands 1–12 all open up as **tool cards you draw when something breaks** (each card on the sea chart shows its symptom); you can also start straight from Island 1 and go in order. Islands 2, 6, 8, 9, 10 and 11 gained "November 2026 additions".

## The 12 islands

| Week | Island | Failure monster | Principle |
| --- | --- | --- | --- |
| 1 | Harbor of Beginnings | the Dice Fiend | tokens, next-token probabilities, sampling and temperature |
| 2 | Bay of Instructions | the Fog Wraith | the model only sees text: background and motivation |
| 3 | Forest of Examples | the Parrot Beast | few-shot, delimiters and XML tags |
| 4 | Mountains of Thought | the Leaping Giant | step-by-step thinking, effort |
| 5 | Format Workshop | the Garble Bot | schemas, structured output, validate-and-retry |
| 6 | Window Desert | the Amnesia Storm | the window budget: compress and prune |
| 7 | Library of Retrieval | the Phantom Librarian | embeddings, chunking, retrieval vs. generation failure |
| 8 | Port of Tools | the Runaway Robot Arm | tool use, the agent loop, MCP, sub-agents |
| 9 | Academy of Skills | the Bloated Tome | progressive disclosure, SKILL.md descriptions |
| 10 | Arena of Evaluation | the Illusion Judge | golden sets, regression tests, LLM-judge bias |
| 11 | Fortress of Shadows | the Injection Assassin | prompt injection, least privilege, human confirmation |
| 12 | Crown Island | the Real-World Overlord | capstone: an evaluable real workflow |

## Files

- `index.html`, `data.js`: the Traditional Chinese original (the source of truth).
- `en/data.js`: English course content, translated by hand. **When `data.js` changes, update this file too.**
- `en/index.html`: generated by `tools/build_en.py` from the original `index.html` using a translation table. The script fails loudly if any interface text is left untranslated. Don't edit it directly.
- `ja/`: Japanese. `ja/data.js` is translated by hand; `ja/index.html` is generated by `tools/build_ja.py`.
- `tools/langs.py`: the shared language switcher; add a line there for a new language and re-run the build scripts.
- `zh-hans/`: Simplified Chinese, generated by `tools/build_zh_hans.py` (OpenCC). Don't edit it directly.
- `課程設計.md`: the full course design document (Traditional Chinese).

## Contributing

Contributions are welcome: more boss cases, more languages, labs that went stale after a model update. One rule: every new item must be able to say *why it works and when it fails*. Templates that only teach tricks won't be accepted.

Always use made-up or de-identified data in experiments.
