# 脈絡群島：提示詞工程與脈絡工程，從零到內化

[English](README.en.md) ・ [日本語](README.ja.md)

一門給零基礎職場人士的 12 週自學／帶課教材，做成一個不用安裝、打開就能玩的網頁。

課程設計結合三套方法，各管一件事：

- **八角框架（Octalysis，周郁凱 Yu-kai Chou 提出的遊戲化框架）** 管「想不想學」：12 座島、失效怪物、徽章、黑天鵝事件、知識城堡風化。
- **番茄鐘** 管「能不能專注」：每座島 6 回合＝6 顆 25 分鐘的番茄鐘。
- **費曼學習法** 管「有沒有真懂」：每座島都要用 12 歲孩子聽得懂的話講出原理。

通關條件不是分數，而是達到「內化層次 3」：能在動手之前預測結果並說出理由。

也可以離線使用：

1. 下載整個資料夾，用瀏覽器打開 `index.html`（不需要網路、不需要安裝）。
2. 另外開一個你平常用的 AI 對話工具，照每座島「實驗室」回合的提示詞去跑。
3. 進度只存在你自己的瀏覽器（localStorage），不會上傳到任何地方；換電腦前到「紀錄」頁匯出。頁面上的「回報這題」只會打開 GitHub 的回報頁面、帶入島號和回合，不帶你寫的內容，要你自己按送出。

講師備課可以在航海圖勾選「自由模式」，解鎖全部島嶼。

## 第 0 週：樹幹（進門先過這裡）

學任何招式之前，先在樹幹走 5 個回合：

1. **T1 記分板**：拿 10 件已經知道答案的事去問 AI，只記「對、錯、講得很順但是錯」三格，不准改提示詞。
2. **T2 弄壞桌子**：故意弄壞三次（同一題開新對話問五次、事實寫上去和不寫、規定塞在長文正中間），每次都先寫預測。
3. **T3 一句話**：用十二歲聽得懂的話講出「模型只看得到桌上的紙」，並對照剛剛親眼看到的結果。
4. **T4 四層**：那一句話、這一輪桌上的全部、每一輪誰負責重擺桌子、「做完」的定義——每一層什麼時候算壞了、怎麼試出來。
5. **T5 畢業**：給兩個沒教過的失敗案例，指出破在哪一層並寫下證據，兩題都對才算過。

過了樹幹，第 1–12 島全部打開，變成**壞了才抽的工具卡**（航海圖卡片上寫著症狀）；想照順序走，也可以直接從第 1 島出發。第 2、6、8、9、10、11 島另外加了「2026 年 11 月補充」。

## 檔案

- `index.html`：畫面、進度、番茄鐘、咒語書匯出。
- `data.js`：全部教學內容（謎題、原理、實驗提示詞、抽問、Boss 案例）。**改內容只要改這個檔。**
- `課程設計.md`：完整課程設計原稿（給講師與管理者）。
- `zh-hans/`：簡體中文版，由 `tools/build_zh_hans.py` 從繁體版自動產生（OpenCC 台灣正體轉大陸簡體，再補上課程用語修正）。**不要直接改這個資料夾**，改繁體版後重跑腳本。
- `en/`：英文版。`en/data.js` 教學內容是人工翻譯的，**改了 `data.js` 要同步改它**；`en/index.html` 由 `tools/build_en.py` 依對照表從繁體版產生，介面有沒翻到的中文腳本會直接報錯。
- `ja/`：日文版。`ja/data.js` 人工翻譯，**改了 `data.js` 也要同步改它**；`ja/index.html` 由 `tools/build_ja.py` 依對照表產生。
- `tools/langs.py`：右上角語言切換的共用設定；新增語言時在這裡加一行，再重跑各個產生腳本。
- `meta.js`：演化紀錄（內容版本、每座島上次驗證和修改的日期），四語共用。
- `更新紀錄.md`：每次內容變動一行。
- `tools/build_all.py`：一行重建全部產生檔再體檢。`tools/check.py`：體檢。`tools/evolve.py`：演化引擎。

## 參與貢獻

歡迎補充：更多 Boss 案例、其他語言版本、模型更新後過時的實驗。原則只有一條：每個新題目都要能說出「為什麼會這樣、何時會失效」，不收只教招式的模板。

實驗請一律使用虛構或去識別化的資料。

最簡單的方式：在課程頁面任何一回合按「回報這題」，或到 issue 用「投稿 Boss 案例」表單。要直接改檔案的話，改完執行 `python3 tools/build_all.py`，看到「錯誤 0 項」再送 PR；每次推送 GitHub 也會自動跑同一套體檢。

## 這門課怎麼長大

AI 工具一直在變，課程一定會過時。所以它有一套自己長大的機制：學員回報和每週自動體檢會把該處理的事浮出來；維護者在本機用演化引擎把它們交給 AI 起草，體檢沒過的修改直接丟掉；最後由人看過才上線。學員在航海圖上會看到「有更新」。詳見 [docs/演化機制.md](docs/演化機制.md)。
